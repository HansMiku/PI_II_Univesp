# Aplicação Web

Esta pasta contém os componentes responsáveis pela disponibilização dos resultados do projeto ao usuário.

## Estrutura

- `backend/` — API e lógica de comunicação com os dados
- `frontend/` — interface, visualizações e recursos de acessibilidade

## Observação
Alterações podem ocorrer ao longo do projeto. Atualizar o readme conforme necessário.

---

## Notas da camada Gold (atualizado em out/2026)

A camada Gold está implementada e disponível no schema `workspace.pi_ii_gold` com 26 tabelas normalizadas. O backend deve consumir essas tabelas para disponibilizar dados ao frontend.

Para detalhes sobre as tabelas e convenções, consulte o README do backend e o README da pasta `03_Gold`.
