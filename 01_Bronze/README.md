# Bronze — Coleta de Dados

Responsável: Luana

Esta pasta contém os códigos responsáveis pela coleta e ingestão dos dados utilizados no projeto.

Os dados serão obtidos por meio das APIs públicas da Câmara dos Deputados e do Senado Federal e armazenados na camada Bronze.

## Entrada
- APIs da Câmara dos Deputados
- APIs do Senado Federal

## Saída
- Dados brutos da camada Bronze

## Observação
Alterações podem ocorrer ao longo do projeto. Atualizar o readme conforme necessário.
